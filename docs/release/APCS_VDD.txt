Scope of change
---------------
- Frontend dataset list now shows per-agent capability badges (A4 / A5) and
  no longer truncates long bundle labels.
- Evidence panel: file paths are rendered as relative paths from `datasets/`
  with the absolute path available as a tooltip; empty snippets no longer
  surface a "no snippet available" stub.
- Backend `_read_bundle_set` auto-detects the `phase5/` subfolder inside each
  APCS bundle and wires the agent5 backend config.
- A new `phase5/` subfolder has been seeded inside every APCS bundle so that
  the Brain orchestrator can drive both Phase 4 and Phase 5 from a single
  selection.

Out of scope
------------
- Real LLM-driven document analysis (planned for the next iteration).
- Real GitHub PR ingestion as Agent 4 input.
- VDD/nulla osta PDF generation.
